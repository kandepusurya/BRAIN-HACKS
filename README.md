🎶 Brain Tones
Brain Tones is a multi-language, theme-enabled music streaming web app designed for a smooth and immersive listening experience. Featuring playlists in 8 languages, dynamic theming, and a sleek UI, this project blends music and culture in one interactive platform.

✨ Features
🎧 Language Playlists:

Telugu, Hindi, English, Kannada, Tamil, Malayalam, Odia, Marathi.

🖌️ Dynamic Themes:

Dark, Halloween, Christmas, Diwali, Holi.

🛠️ Interactive Music Player:

Play/pause, skip, shuffle, repeat modes.

Playlist sidebar with track durations.

🔍 Smart Search:

Autocomplete search box powered by JavaScript.

🎥 Background Video:

Each theme sets a unique background video that persists across pages.

📂 Project Structure
File / Folder	Purpose
index.html	Login/Register landing page.
mainpage.html	Theme selection + link to language playlists.
AllLanguages.html	Grid of available languages for music selection.
musicplayer.html / languageplayer.html	Full-feature music player.
Search.html	Standalone search page with autocomplete.
music-list.js	Array of songs organized by language.
script.js	Music player logic: load songs, handle controls, playlist interactions.
suggestions.js	List of search suggestions.
suggestionsscript.js	Logic for autocomplete functionality.
videoscript.js	Manages dynamic background video switching.
*.css	Stylesheets for each page/module.
